# 发票盒子 Windows 桌面版 6.6.0

## 下载和使用

1. 在 [GitHub Releases](https://github.com/dayesann/InvoiceBox-/releases/latest) 下载 `InvoiceBox-6.6.0-windows-x64.zip`。
2. 解压整个 ZIP。保持 `InvoiceBox.exe` 与 `_internal` 文件夹在同一目录。
3. 双击 `InvoiceBox.exe`，程序自动打开默认浏览器中的本机页面。无需安装 Python 或 Node.js。
4. 保持启动窗口打开；使用结束后关闭该窗口即可退出。若浏览器没有自动打开，可复制启动窗口显示的本机网址。

适用 Windows 10/11 x64。当前发布包没有数字签名；可核对发布页的 SHA-256 校验文件。未在 Windows ARM 或 macOS 验证。

## 本次更新

- 自动关联综合金额、交通类型、原文件批次名称、下载序号、日期和路线；同额候选无法区分时保留待关联。
- 将行程单拖到发票上可手动关联；点击卡片上的“关联”可解除、换绑或重新匹配。多个行程单可以关联同一发票。
- 关联和拖拽排序保存到本地，重启后保留；不同批次不自动配对。
- 列表、预览、下载和报销材料包使用统一关联规则。行程单不重复计入报销合计。
- 拼版保留 PDF 的可见区域和全部页面。图片导入不再缩成约 72 DPI 的 A4 图片。
- OFD 导入时直接转成 PDF，尽量保留文字和矢量内容，打印时复用结果。
- 拼版视图点击“打印”打开生成的高清 PDF，在浏览器 PDF 阅读器中打印。报销单视图仍使用浏览器打印。

金额、日期或识别结果有误时可在卡片中修正。自动配对仅为建议，请核对原件。此版本对扫描图片主要提供导入、拼版和人工填金额，未集成离线图像文字 OCR 引擎。

## 数据和升级

默认数据目录为 `%LOCALAPPDATA%\InvoiceBox_V5`，沿用原桌面版路径，票据保存在 `invoices` 子目录。资料保存在本机，不随发布包上传。

升级前在旧版“设置 → 创建备份”导出 ZIP，再关闭旧版。将新版解压到新目录运行，不要把两个版本同时用于同一数据目录。程序启动使用可用的随机本机端口，因此不同次启动网址可能变化。

原有批次管理、分类调整、CSV、报销材料包和备份恢复功能保留。OFD 字体、签章与版式兼容性取决于源文件，打印前检查预览；旧版已转换为低分辨率 PDF 的票据需要重新导入原文件，升级无法恢复丢失的细节。

## 从源码构建

Python 3.12 x64，在仓库根目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements-desktop.txt
.\.venv\Scripts\python -m unittest discover -s tests -p test_desktop.py -v
.\.venv\Scripts\python -m PyInstaller --noconfirm desktop.spec
```

构建输出在 `dist/InvoiceBox`。只打包此输出目录，不要打包本地票据、database.json 或 settings.json。

`INVOICEBOX_DATA_DIR` 环境变量可指定隔离测试数据目录；`InvoiceBox.exe --no-browser` 可禁止自动打开浏览器。
