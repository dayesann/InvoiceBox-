# 发票盒子：网站版

这个目录基于 2026-11-05 的线上发布文件重建。Cloudflare 项目为直接上传，未连接 Git；网站原来的 Vue 工程源码目前没有找到。`vendor/site-2026.11.05.1.js` 是已发布的压缩构建产物，不是恢复出的原始源码；`src/matching.js` 是此次新写、可单独维护的匹配模块。构建脚本验证发布包的 SHA-256 并在明确的函数入口接入新模块，校验失败会中止。

## 本地运行

需要 Node.js 20 或更高版本。首次运行：

```powershell
cd web
npm ci --ignore-scripts
npm run build
npm test
npm run dev
```

在本机浏览器打开终端显示的 `http://127.0.0.1:4173`。服务仅监听本机。票据沿用原网站的当前页面内存模型，刷新、关闭页面后需要重新添加；票据本身不会写入这个仓库。OCR 和 PDF 运行资源在构建时从锁定版本依赖复制到 `dist`，供浏览器同源加载。

## 关联规则

系统使用交通类型、金额、原始批次文件名、提取日期和已有路线信息生成并排序候选；金额和类型发生明确冲突时不建议关联。同额多候选无法区分时保持待处理。自动结果直接分组，左侧关联的卡片相邻显示。用户可以将行程单卡片拖到对应的发票卡片上，手动建立或修改关联；也可点击卡片上的“关联”进行选择、解除或重新匹配。下载或打印前会提示未关联附件以及已确认关系中的明显冲突。列表、预览、导出按相同规则计算关系，修改显示名称不会改变原始文件名依据。

金额一致并不能证明票据属于同一行程，原文件中的下载序号也可能因下载顺序不同而不对应。提取日期可能是开票日期或行程日期，只作辅助排序。识别文字不足、金额错误、分类错误或多张相似单据都可能使结果错误或需要人工处理，应对照原件检查。网站当前不是桌面 Flask 应用，桌面版原有缺陷也尚未修复。

## 打印与生成速度

2026.11.10.1 修复 OFD 导出黑底：JPEG 编码前在画布内容后合成白底，保留文字、半透明印章和输出尺寸；PNG 预览保持原有透明度。`tests/ofd-canvas.browser.html` 提供实际浏览器像素回归检查（在构建目录下的 `tests/` 放置该文件后访问），覆盖 600/1200 尺寸、白底、半透明墨迹及 PNG 透明度。

PDF 原件沿用矢量页面和原有图片，不做降采样；报销单仍按 300 DPI 渲染。OFD 默认按放入最终 A4 页面后的尺寸生成约 600 DPI 的位图，可在打印设置中切换到 1200 DPI；OFD 精度越高，生成时间和内存占用越大。报销单和票据在同一个 PDF 中生成，避免再次读取和复制整份文件。同一页面内复用最近的 OFD 渲染结果，缓存仅在内存中，删除票据、清空和离开页面时会相应释放。

## 本次验证和局限

- 合成 PDF 在浏览器中完成导入、卡片拖拽、改显示名称、解除、重新匹配及分类切换；实际下载的 PDF 显示与列表一致的费用项及附单编号，附件金额未重复计入。
- 使用本机备份中已提取的两组票据文本做离线模拟，对照此前人工重命名分组：10 组建议与既有分组一致，其中 2 组利用了原文件下载序号。这不是对完整浏览器识别流程的真实票据验收，也不能确认两组就是用户刚上传的票据。
- 一张由合成 PDF 转成的旋转测试图片可导入并加载 OCR，但其金额未识别出来，显示为 0；需检查并手动修正金额。真实票据 OCR、OFD 和多页文件尚未在本地修复版逐一完成端到端验证。
- 普通 PDF 拼版现在读取每页自带的可见区域（CropBox）和旋转角度，不再单凭整张物理页面的宽高判断方向；票面按源文件设置的可见区域输出，不按推测裁切。
- 使用 8 个合成 PDF 和 3 个双页[公开 OFD 测试样本](https://github.com/isee15/ofdjs/blob/main/test/fixtures/test.ofd)对照：新旧输出页数和 PDF 中的可提取文字一致；600 DPI 模式在 300 DPI 渲染检查中视觉差异很小。尚未用实体打印机或扫码器验收。

## 发布与隐私

`dist` 为生成目录，不应将个人发票、识别内容、凭据或审查样本放入构建目录或提交到仓库。Cloudflare `invoicebox-web` 项目采用直接上传，GitHub 更新不会自动触发网站发布。运行 `npm ci --ignore-scripts`、`npm test` 和 `npm run build` 后，可在 Cloudflare Pages 项目中将 `web/dist` 的内容作为新部署上传；先在预览环境用合成样本验证，再发布到生产环境。原有部署保留，可用于回退。
